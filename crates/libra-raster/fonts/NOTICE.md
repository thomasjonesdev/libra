# Bundled fonts

These files are the paint-path fonts (`include_bytes!` in `libra-raster`).
Bytes are the same as `assets/fonts/` in the Libra checkout. Both families
are SIL Open Font License 1.1 — see `OFL.txt`.

- **Work Sans** (Medium, Bold, Italic) — Copyright 2019 The Work Sans Project Authors (https://github.com/weiweihuanghuang/Work-Sans)
- **Space Mono** (Regular) — Copyright 2016 The Space Mono Project Authors (https://github.com/googlefonts/spacemono)
