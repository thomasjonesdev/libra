# Gloss — agent brief

If you are editing the Gloss **UI** (`.lx`, gallery-facing chrome, the
editor shell), read [[docs/catalog-handoff]] first. Tabs, Search, Chip,
Toast, and Toolbar shipped in the Libra catalog on 2026-08-25; the
homemade `ListItem` + ghost-`x` tab strip and the filter `Input` are
the first things to replace. Do not reimplement them.
