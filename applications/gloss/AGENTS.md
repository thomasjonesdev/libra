# Gloss — agent brief

If you are editing the Gloss **UI** (`.lx`, gallery-facing chrome, the
editor shell), read [[docs/catalog-handoff]] first. The shell uses the
catalog chrome: `<Toolbar>`, `<Search>`, `<Tabs>`/`<Tab>`, `<StatusBar>`,
and `<Toast>`. Do not reimplement them with `ListItem` + ghost buttons.
Chip is still later (facet filters).
