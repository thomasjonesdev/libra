# D.4 Adoption path (containing the theoretical)

## In this vault

- Parent: [[appendix-d-team-and-use-case-fit-ground-crew-operations-reference-case]]

---

1. **Phase-0 gate** (framework): determinism proven end-to-end before any adoption conversation.
2. **Pilot**: one internal, non-crew ops tool (an ops console or monitoring surface) built by 2–3 people; validates DX claims, [[22-performance-budgets|§22]] budgets on real telemetry shapes, and the [[appendix-d.2-division-of-labor-multidisciplinary-team|D.2]] division of labor.
3. **Coexistence**: Libra surfaces ship alongside existing Tauri surfaces; no big-bang rewrite is ever on the table.
4. **Crew surfaces last**: touch/OSK ([[19.1-touch-first-class-not-an-afterthought|§19.1]]) hardened and field-validated on the pilot class of hardware before anything crew-facing.
