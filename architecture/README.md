# Architecture vault

Open this folder as an Obsidian vault (`File → Open vault → architecture/`).

| Note | Role |
|---|---|
| **`AGENTS.md`** | **End-to-end brief — start here (agents & humans)** |
| `Architecture Home.md` | Vault entry + full outline |
| `Map of Content.md` | Graph-friendly MOC |
| `SECTION-INDEX.md` | `§N.N` → file lookup |
| `Plans Index.md` | Staging / execution plans |
| `sections/` | §1–§26 (one note per section/subsection) |
| `appendices/` | Appendices A–D |
| `plans/` | Plans with architecture wiki-links |

Citations in code stay as `ARCHITECTURE.md §N.N` (or `§N.N`). Resolve them via `SECTION-INDEX.md`.

Repo-root `CLAUDE.md` points agents at this vault and at `AGENTS.md` first.
