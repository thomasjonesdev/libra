# 7.1 The Built-in Catalog

## In this vault

- Parent: [[07-components]]
- Execution: [[PLAN-CATALOG]] (inventory) · [[PLAN-COMPONENTS]] (structure + authoring) · [[PLAN-UI-SURFACE]] · [[PLAN-TOKENS]]

## In code

- `crates/libra-components/src/catalog/` — **one module per component** (`build` + `paint`, tokens only)
- `crates/libra-components/src/catalog/mod.rs` — the authoring guide (how to add a component)
- `crates/libra-components/src/catalog/text.rs` — the smallest build+paint component; copy it as a template
- `crates/libra-components/src/{layout,paint}.rs` — the thin dispatchers into the catalog

---

Closed and curated — not an open plugin bazaar. The target set is sized for
**ops / mission-control** UIs **and** parity with a modern native catalog
(mirror: Vercel json-render React Native standards — capability shape, not
RN APIs). Implement **one component at a time**; styling only through
[[11-theming|§11]] tokens ([[PLAN-TOKENS]]).

### Layout

Column, Row, Grid, Split (draggable), Panel, Scroll, Spacer, Separator,
SafeArea (shell insets), Box/Container (tokenized padding/surface — may
fold into Column/Row attrs)

### Text & display

Text, Heading, Label, Paragraph (or Text roles), Badge, Status, Icon,
Image, Avatar, Chip, Markdown (read-only subset), Tooltip

### Controls

Button, ButtonGroup, Input, Textarea, Search, Checkbox, Switch, Radio,
Select, Combobox, Slider, Stepper

### Feedback

Spinner, Progress

### Composite / chrome

Card, ListItem, Tabs, StatusBar, Toolbar, CommandPalette, Dialog/Modal,
Toast, ContextMenu

### Data

Table (virtual; headless column model à la TanStack Table — column defs,
sorting/filtering/grouping live as state), VirtualList, Tree, Chart
(line/area/scatter/bar; data-plane-aware, [[14-data-plane|§14]]),
Sparkline, Gauge, LogView (virtual, follow-tail)

### Media

Video ([[09.5-video|§9.5]]) — Phase 5+

### Sources (invisible, zero-layout; [[12.5-declarative-subscriptions|§12.5]])

Frames, Interval, Stream

### Escape hatch

Canvas ([[07.4-canvas|§7.4]])

Every component ships with: semantics (role/label/state for accesskit +
queries), keyboard behavior, focus behavior, **theme-token styling**, and
its own snapshot fixtures. OS sheets (alert/share/open-URL) are
[[12.1-effect-vocabulary|§12.1]] effects — see
[[PLAN-NATIVE-INTEGRATIONS]] — not paint-path I/O.

### Authoring surface (approachable by design)

One clear place for each job ([[PLAN-COMPONENTS]]):

- **Change the global look** — edit `themes/*.toml` ([[11-theming|§11]],
  [[PLAN-TOKENS]]); hot-reloads in the running app / gallery. No Rust.
- **Change one component** — open its single file under
  `crates/libra-components/src/catalog/`; it reads only `theme.*` tokens (a
  test forbids raw color literals — [[PLAN-TOKENS]] T3).
- **Add a component** — copy `catalog/text.rs`, wire the grammar in both
  engines + a `conformance/` fixture ([[06.4-one-grammar-two-engines|§6.4]]),
  add a gallery cell. The guide is `catalog/mod.rs`.
- **Preview** — `examples/gallery`, the Storybook-style workbench
  ([[PLAN-GALLERY]]): sidebar → isolated component canvas (variants +
  playground) → controls. Adding a catalog component includes adding its
  canvas block.

**Shipped today (subset):** Column, Row (incl. `width={px}` and weighted
`grow={n}` pane sizing), Scroll (vertical viewport — [[PLAN-SCROLL]]), Text,
Heading (`level` 1–4 → type ramp), Button, Badge (`tone` → status tokens),
Progress (`value={0..1}`, literal or bound), Input, Textarea (hard newlines;
soft wrap + IME later), ListItem (selected/hover `surface_raised` washes),
Split (two-pane draggable splitter, model-owned fractions — 2026-07-19),
ContextMenu (anchored floating menu on the Dialog overlay machinery; the
anchor is a deterministic input — 2026-07-19), Dialog (in-tree modal: `theme.scrim` + centered panel, detached overlay
layout, scrim as hit barrier; mount via `<if>` — 2026-07-19), Chart,
Sparkline, Spacer, Separator, Alert (status-token callout), Card/Panel
(surface containers), Skeleton (static), Avatar (initials), Switch /
Checkbox / Radio (model-owned; check glyph via Polyline, circles via
full-radius RRect), Drawer (edge-anchored modal; `side="bottom"` is the
Sheet), Slider (model-owned, generalizes the Split-drag machinery), Search
(Input chrome + optional Enter `onSubmit` — 2026-08-25), Chip
(model-owned `selected`, optional trailing `onRemove` — 2026-08-25), Tooltip
(hover-input floating label, second paint pass), Breadcrumb, Pagination
(fully generated, windowed), Stepper (index-derived status), Timeline
(direct per-item `done`), Frames, Interval, Stream — plus the
workbench. Remainder is
[[PLAN-CATALOG]].

**Hover** is an explicit paint input, not ambient state: the shell
feeds its live cursor, the harness feeds none by default (canonical
frames are hover-free) or pins a point via `hover(sel)` — so hover
snapshots stay byte-exact (Appendix A holds).
