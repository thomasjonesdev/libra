# 13.2 State snapshots

## In this vault

- Parent: [[13-persistence]]

---

Because `State: Serialize`, the runtime provides `Effect::SnapshotState { key }` and rehydration at startup — used for hot-reload state preservation ([[18.2-the-iteration-loop-the-dx-centerpiece|§18.2]]), crash-recovery ("restore session?"), and session export for bug reports ([[18.5-time-travel-and-session-capture|§18.5]]). Snapshots exclude data-plane buffers (handles reattach; buffers are re-fed or empty).
