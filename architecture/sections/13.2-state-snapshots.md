# 13.2 State Snapshots

## In this vault

- Parent: [[13-persistence]]

## In code

- `crates/libra-platform/src/lib.rs` — `run_rehydrating` (serde-JSON snapshot on close, restore on launch)

---

Because `State: Serialize`, the runtime provides `Effect::SnapshotState { key }` and rehydration at startup — used for hot-reload state preservation ([[18.2-iteration-loop|§18.2]]), crash-recovery ("restore session?"), and session export for bug reports ([[18.5-time-travel-capture|§18.5]]). Snapshots exclude data-plane buffers (handles reattach; buffers are re-fed or empty).
