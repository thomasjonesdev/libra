# 7.4 Canvas — Advanced Custom UI

## In this vault

- Parent: [[07-components]]

---

`Canvas` is the fully custom escape hatch: the paint context exposes the complete drawing vocabulary (paths, béziers, gradients, glyph runs, images, layers, clips, transforms), plus retained-layer helpers so static portions cache. This is where bespoke visualizations live — topology graphs, timelines, mini-maps, orbital plots. Animation uses renderer-side animated tokens ([[09.5-video|§9.5]]) or `Sub::frames()`; the data plane ([[14-data-plane|§14]]) feeds it at high rate. The contract: Canvas emits commands, never owns pixels — so a custom component's output is exactly as testable as a Button's.
