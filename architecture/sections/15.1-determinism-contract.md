# 15.1 The Determinism Contract

## In this vault

- Parent: [[15-testing]]

---

1. Actions are pure ([[05.3-purity-rules|§5.3]]) — enforced by lint.
2. Views are data with no computation ([[06.3-grammar-restrictions|§6.3]]).
3. Effects are data; the runtime is the only I/O actor ([[12-effects-runtime|§12]]).
4. Rendering is a pure function of the display list ([[09.2-canonical-executor|§9.2]]); text quantized ([[10-text|§10]]); fonts bundled; animations evaluate at targets or injected clocks ([[09.5-video|§9.5]]).
5. High-rate data crosses one fortified boundary ([[14.4-determinism|§14.4]]).
