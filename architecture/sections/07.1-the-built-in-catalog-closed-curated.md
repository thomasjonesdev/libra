# 7.1 The built-in catalog (closed, curated)

## In this vault

- Parent: [[07-components]]
- Execution: [[PLAN-CATALOG]] · [[PLAN-UI-SURFACE]] · [[PLAN-TOKENS]]

---

Closed and curated — not an open plugin bazaar. The target set is sized for
**ops / mission-control** UIs **and** parity with a modern native catalog
(mirror: Vercel json-render React Native standards — capability shape, not
RN APIs). Implement **one component at a time**; styling only through
[[11-theming-and-design-tokens|§11]] tokens ([[PLAN-TOKENS]]).

### Layout

Column, Row, Grid, Split (draggable), Panel, Scroll, Spacer, Separator,
SafeArea (shell insets), Box/Container (tokenized padding/surface — may
fold into Column/Row attrs)

### Text & display

Text, Heading, Label, Paragraph (or Text roles), Badge, Status, Icon,
Image, Avatar, Chip, Markdown (read-only subset), Tooltip

### Controls

Button, ButtonGroup, Input, Textarea, Search, Checkbox, Switch, Radio,
Select, Combobox, Slider, Stepper

### Feedback

Spinner, Progress

### Composite / chrome

Card, ListItem, Tabs, StatusBar, Toolbar, CommandPalette, Dialog/Modal,
Toast, ContextMenu

### Data

Table (virtual; headless column model à la TanStack Table — column defs,
sorting/filtering/grouping live as state), VirtualList, Tree, Chart
(line/area/scatter/bar; data-plane-aware, [[14-the-high-rate-data-plane|§14]]),
Sparkline, Gauge, LogView (virtual, follow-tail)

### Media

Video ([[09.5-video-planned-not-early-phase|§9.5]]) — Phase 5+

### Sources (invisible, zero-layout; [[12.5-declarative-subscriptions-effects-as-mount-scoped-data|§12.5]])

Frames, Interval, Stream

### Escape hatch

Canvas ([[07.4-canvas-advanced-custom-ui|§7.4]])

Every component ships with: semantics (role/label/state for accesskit +
queries), keyboard behavior, focus behavior, **theme-token styling**, and
its own snapshot fixtures. OS sheets (alert/share/open-URL) are
[[12.1-the-effect-vocabulary-closed-versioned|§12.1]] effects — see
[[PLAN-NATIVE-INTEGRATIONS]] — not paint-path I/O.

**Shipped today (subset):** Column, Row, Text, Button, Input, Chart,
Sparkline, Frames, Interval, Stream — plus gallery matrix. Remainder is
[[PLAN-CATALOG]].
