# 9.1 The Display List

## In this vault

- Parent: [[09-rendering]]

## In code

- `crates/libra-draw/src/lib.rs` — `DrawCmd` and the display list
- `crates/libra-raster/src/lib.rs` — clip stack (`PushClip`/`PopClip`): path fills via a tiny-skia `Mask`, text/strips via a bounds check; shared by `render` + `render_damage` (byte-equivalent, Appendix A)

**Implemented today** is a subset of the vocabulary below: `Clear`, `Rect`,
`RRect`, **`StrokeRRect { rect, radius, width, color }`** (stroke centered
on the rect edge; catalog chrome insets by `width/2` so Dialog / Input /
Tooltip frames sit inside the fill and follow the radius — 2026-08-25),
`Text`, `Polyline`, `Strips`, and **`PushClip { rect }` / `PopClip`**
(rect clip, no radius yet — [[PLAN-SCROLL]]). Layers, gradients, images, and
shadows remain aspirational. `StrokeRect` / `StrokePath` in the vision
enum below stay unbuilt — `StrokeRRect` with `radius` 0 covers a stroked
square without a second variant.

---

The universal currency between components and executors:

```rust
pub enum DrawCmd {
    FillRect   { rect: Rect, fill: Fill },                       // Fill: solid | linear-gradient
    FillRRect  { rect: Rect, radius: Radius, fill: Fill },
    StrokeRect { rect: Rect, stroke: Stroke },
    FillPath   { path: PathId, transform: Affine, fill: Fill },
    StrokePath { path: PathId, transform: Affine, stroke: Stroke },
    GlyphRun   { run: GlyphRunId, origin: Point, color: Color },
    Image      { image: ImageId, dst: Rect, fit: Fit, sampling: Sampling },
    Shadow     { rect: Rect, radius: Radius, blur: f32, color: Color },
    PushLayer  { id: LayerId, bounds: Rect, opacity: f32 },      // cacheable subtree
    PopLayer,
    PushClip   { rect: Rect, radius: Option<Radius> },
    PopClip,
}
```

Paths, glyph runs, and images are interned resources referenced by id — the display list stays small, diffs cheaply, and hashes fast. A frame is `(Vec<DrawCmd>, CacheActions)` where `CacheActions` tells the executor which layers/atlases/geometries to create, reuse, or evict.
