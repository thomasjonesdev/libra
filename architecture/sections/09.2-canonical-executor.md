# 9.2 The Canonical Executor

## In this vault

- Parent: [[09-rendering]]

## In code

- `crates/libra-raster/src/lib.rs` — tiny-skia + fontdue → deterministic RGBA/PNG

---

`tiny-skia` rasterizes the display list into an RGBA framebuffer; `softbuffer` blits it into the winit window. Properties this buys:

- **Bit-exact reproducibility** across machines, OSes, CI containers. No GPU, no driver, no display server needed. (tiny-skia is a pure-Rust port of Skia's software pipeline — this is its explicit design goal.) macOS, Windows, and Linux must produce the same PNG from the same display list — that is the content half of [[19.4-desktop-os-matrix|§19.4]]. OS chrome never enters this path.
- **Screenshot tests are `assert_eq!` on bytes** ([[15.5-snapshot-tests|§15.5]]). No perceptual-diff thresholds, no "2% fuzz allowed."
- One rendering truth: unlike stacks where the software path is a poor cousin, here the CPU renderer *is* the product.
