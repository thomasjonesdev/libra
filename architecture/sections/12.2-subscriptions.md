# 12.2 Subscriptions

## In this vault

- Parent: [[12-effects-runtime]]

---

`Sub` covers ongoing sources, declared by `subscriptions(state)` and diffed by the runtime (start new, cancel removed): `Sub::frames()` (vsync-coalesced ticks), `Sub::stream(id)` (websocket/process/data-plane events), `Sub::interval(...)`, `Sub::hotkeys(...)`, `Sub::window_events()`. Deriving subs from state means "connect while this screen is open" is a pure function — and testable as one. The same sources can be declared in markup as mount-scoped source elements ([[12.5-declarative-subscriptions|§12.5]]); the runtime diffs the union of both forms.
