# 1.5 Who This Is For

## In this vault

- Parent: [[01-vision]]

---

The primary user is the author (and teams like the author's): engineers building **operational, data-dense, mission-critical desktop tools** — telemetry dashboards, control surfaces, ops consoles — who need to *prove* the UI behaves correctly, not just believe it. The secondary audience is AI agents: the same determinism that makes tests exact makes the framework legible to agents (see [[16-automation-server|§16]]).
