**Status: M4 usable; M1 started.** CLI apply/undo/backlinks/index/neighbors/
suggest-links work against a real vault.
The Libra app lists notes, opens them preview-first, saves through the patch
layer, and undoes the last run. Rail: new note, quick open, daily note, links
drawer, undo. See `applications/gloss/docs/09-app-functions.md`.

Gloss points at an existing Markdown vault. No import, no new format.
The product is the bundle in `docs/11-coherence.md`, not a cloned
editor. Obsidian vaults are a first-class input.
Every write is a structured patch with `expect_hash`. Paths are
`(RootId, RelPath)` only. The core crate has no UI types.

The v1 editor is Libra `<Textarea>` (PLAN-TEXTAREA stage 1), not CodeMirror.
Styled markdown display already ships in `libra-markdown` / `<Markdown>`.
§24 fences the edit buffer, not that paint. Soft wrap, `Effect::File*`,
and Keychain are the remaining framework gaps
(`applications/gloss/docs/10-libra.md`). Vault open uses
`Effect::PickFolder`. Note bytes still move through Process-to-self.
M1/M2 do not wait on those gaps. What we are building:
`applications/gloss/docs/11-coherence.md`.
