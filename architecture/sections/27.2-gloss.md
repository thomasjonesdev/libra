---

**Status: M4 in progress.** CLI apply/undo/backlinks work against a real vault.
The Libra app lists notes, opens them preview-first, saves through the patch
layer, and undoes the last run. Rail: new note, quick open, daily note, links
drawer, undo. See `applications/gloss/docs/09-app-functions.md`.

Gloss is a Markdown vault editor. Obsidian vaults are a first-class input.
Every write is a structured patch with `expect_hash`. Paths are
`(RootId, RelPath)` only. The core crate has no UI types.

The v1 editor is Libra `<Textarea>` (PLAN-TEXTAREA stage 1), not CodeMirror.
A markdown-aware crate (wikilink paint, ghost text) is the next framework
gap when Tab lands. Vault open uses `Effect::PickFolder` (native folder
sheet). Note bytes still move through Process-to-self, not `Effect::File*`.
