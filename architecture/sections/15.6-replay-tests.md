# 15.6 Replay Tests

## In this vault

- Parent: [[15-testing]]

## In code

- `crates/libra-test/src/replay.rs` — `Replay` / `Harness::replay`
- `cli/libra/src/test/args.rs` — `--replay`

## Implemented today

A `.lreplay` file is JSON: `steps` of `{action, arg?, discard?}`, optional `preludeDiscard`, then `stateHash` and `frame`. Both hashes are blake3. `stateHash` is the bindable fields (`name=value` lines, redacted fields omitted). `frame` is the canonical PNG (density 1, the snapshot path). `Harness::replay` dispatches each action by its public name, drops the named number of intercepted effects, and fails if any effect is still queued or either hash differs.

`libra test --replay bug.lreplay` sets `LIBRA_REPLAY` to that path and selects tests whose name contains `lreplay`. The test loads the file and calls `replay`. A fixture lives at `crates/libra-test/tests/fixtures/increment.lreplay`.

Effect result bodies (HTTP, dialogs) and tapes are still open. Scrubbing the log in the inspector is [[18.5-time-travel-capture|§18.5]] and is still open.
