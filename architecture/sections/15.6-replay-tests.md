# 15.6 Replay Tests

## In this vault

- Parent: [[15-testing]]

---

Any recorded session ([[18.5-time-travel-capture|§18.5]]) exports as a `.lreplay` (init snapshot + action log + effect results + tapes). `libra test --replay bug_1042.lreplay` re-runs it and asserts final state hash + final frame bytes. A user's bug report becomes a committed regression test verbatim.
