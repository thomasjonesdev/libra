# 15.3 Component Tests

## In this vault

- Parent: [[15-testing]]

---

```rust
#[test]
fn count_renders_and_increments() {
    let mut h = Harness::render(AppState::init());
    h.get(by::test_id("count")).assert_text("0");
    h.click(by::role(Role::Button).with_text("+"));
    h.get(by::test_id("count")).assert_text("1");
}
```

The harness builds the real view (interpreter in test builds), lays it out at a virtual viewport, and dispatches through the real routing — a click hit-tests real geometry and dispatches the component's real action. Queries run against the semantics tree ([[17-accessibility|§17]]): `by::role`, `by::label`, `by::test_id`, `by::text` — the same selectors Testing Library made standard, resolved against the same tree assistive tech sees.
