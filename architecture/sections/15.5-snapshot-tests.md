# 15.5 Snapshot Tests

## In this vault

- Parent: [[15-testing]]

## In code

- `crates/libra-test/src/lib.rs` — `assert_snapshot()` (byte-exact PNG; writes `.actual.png` + `.diff.png` on mismatch)

---

```rust
#[test]
fn dashboard_nominal() {
    let mut h = Harness::render(AppState::init()).viewport(1280, 800).theme("libra-dark");
    h.feed_tape("fixtures/telemetry_nominal.ltape");
    h.dispatch(Action::Frame(FrameInfo::at(t(3.0))));
    h.assert_snapshot("dashboard_nominal");            // PNG byte equality
}
```

Snapshots are deterministic PNGs (fixed encoder settings) committed to the repo. Failure output: expected / actual / diff-heatmap triplet. `libra test --validate` (env: `LIBRA_VALIDATE=1`) re-records after intentional changes. Because rendering is bit-exact, there are **no tolerance thresholds** — a one-pixel change is a real change. This includes *charts*: recorded tape in, rendered plot bytes out — regression tests for visualizations, which effectively no mainstream stack offers.
