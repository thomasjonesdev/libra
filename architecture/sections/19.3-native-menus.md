---

Native menubars and right-click popups are **OS chrome** ([[19-platform-integration|§19]]). They never enter the display list. Apps declare them as a typed projection of State; the shell builds `muda` widgets and routes clicks through the same effects sink as AccessKit `Click`s.

There is **no `<MenuBar>` element**. A native menu has no geometry. Putting one in `.lx` would invent a second, non-layout tree inside a grammar that exists to describe layout — the same rejection as `TrayDecl` ([[PLAN-RESIDENCY]]).

```rust
fn menu(state: &App) -> MenuDecl { /* File / Go / View */ }

fn context_menu(state: &App) -> Option<MenuDecl> { /* after onMenu */ }

libra::app! { state: App, menu: menu, context_menu: context_menu, /* … */ }
```

## The pieces

| Piece | Layer | Contract |
| --- | --- | --- |
| `MenuDecl` / `Menu` / `MenuItem` | `libra-core` | Pure — no `muda` types. Items are `Action` (reflected name + optional static `arg`), `Separator`, or `Submenu` |
| `App::menu(&self)` | `libra-core` | **State-dependent** (Recents change). Empty (default) leaves the host OS menu alone |
| `App::context_menu(&self)` | `libra-core` | After a right-click `onMenu` dispatch. `None` keeps painted `<ContextMenu>`; `Some` is a native popup |
| `menu:` / `context_menu:` | `app!` (§5.8) | Optional paths, same shape as `subscriptions:` |
| `validate_menu` | `libra-core` | Every action resolves; accelerators parse as §19.2 chords |
| `muda` build + diff | shell | Rebuild menubar only when the decl changes. macOS keeps Hide / Quit on the app menu. Linux logs a typed refusal (winit has no GTK window; GTK is not linked — N8). A context decl that is empty or has more than one menu is refused out loud |
| `h.menu()` / `h.click_menu` | harness | No OS. `click_menu("newNote", None)` / `click_menu("switchVault", Some(path))` |

## Right-click

1. The shell still hits `onMenu` on the laid item (selection / targeting).
2. After that dispatch, if `context_menu()` is `Some`, `muda` pops up at the cursor.
3. If `None`, today's painted `<ContextMenu>` path is unchanged (notes, gallery).

## Determinism

Menus are off the paint contract. Snapshots do not include them. The decl itself is data — asserted in unit and harness tests with zero window.
